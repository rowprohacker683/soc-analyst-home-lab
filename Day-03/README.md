# Day 03 – Splunk Installation & Data Ingestion

## Objectives

- Install and configure Splunk Enterprise
- Understand Splunk user roles
- Create Normal User and Power User accounts
- Ingest Linux log data
- Ingest Web Application log data
- Verify indexed events
- Understand Splunk indexes and time ranges

## Tasks Completed

### 1. Splunk Installation
Installed and configured Splunk Enterprise 8.2.6 in the Windows 10 virtual machine.

### 2. User & Role Management
Created and tested:
- Normal User
- Power User
- Administrator

Learned the basics of Role-Based Access Control (RBAC) and the Least Privilege principle.

### 3. Log Data Ingestion
Uploaded:
- Linux log data
- Web Application log data

### 4. Index Verification

Created/used the `test` index and verified that approximately 39K events were indexed.

### 5. Searching Events

Used Splunk Search & Reporting to verify the ingested data.

The uploaded logs contained older timestamps, so the `All time` time range was required to view the events.

## Skills Practiced

- Splunk Enterprise
- Log Ingestion
- Index Management
- User & Role Management
- RBAC
- Log Searching
- Event Analysis
- Time Range Filtering
