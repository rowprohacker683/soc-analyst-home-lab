Day 01 - Introduction to SOC

## What is SOC?

A Security Operations Center (SOC) is a team responsible for monitoring,
detecting, analyzing and responding to cybersecurity incidents.

## Types of SOC

- In-House SOC
- Virtual SOC
- Co-Managed SOC
- Command SOC

## Roles in a SOC Team

- Tier 1 Analyst
- Tier 2 Analyst
- Tier 3 Analyst
- Threat Hunter
- Security Engineer

## Important Tools

- SIEM
- EDR
- Firewall
- IDS/IPS

- Understanding SOC operations
