Zero-Day Vulnerability

A zero-day vulnerability is a security weakness that is unknown to the vendor or has not yet been patched.

Zero-Day Attack

A zero-day attack occurs when an attacker exploits a zero-day vulnerability before a security fix is available.

Types of Malware
Backdoor: Provides unauthorized access to a system while bypassing normal authentication.
Trojan: Malicious software that disguises itself as a legitimate or useful program.
Worm: Malware that can automatically spread from one system to another, often through networks.
Virus: Malicious code that attaches itself to files or programs and spreads when the infected file is executed.
Ransomware: Malware that locks or encrypts data and demands payment from the victim.
Spyware: Malware designed to secretly monitor or collect information from a system.
